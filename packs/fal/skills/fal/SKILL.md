# fal.ai

fal hosts over a thousand generative models behind one queue API. This pack gives you the catalog, each model's real input schema, and a runner that saves every output file to the library.

## Which tool

- `fal_search_models`: find models. Keyless. Filter with `category` (`text-to-image`, `image-to-image`, `text-to-video`, `image-to-video`, `text-to-speech`, `speech-to-text`, `text-to-audio`, ...) or `modality` (`image`, `video`, `audio`, `text`, `3d`). Results are cached, so repeated searches are free.
- `fal_describe_model`: the model's input fields, JSON Schema, output fields, price (when `FAL_KEY` is set) and a ready `fal_run` call. Always call it before running a model you have not used in this conversation.
- `fal_run`: run any model with `{model, input}`. The input is validated against the model schema before anything is sent, so a schema error costs nothing. It is a long-running tool: you may get a job handle to poll.
- Per-model tools such as `fal_flux_dev`, `fal_nano_banana_pro`, `fal_kling_video_v3_pro_image_to_video` and `fal_minimax_speech_2_8_hd` take the model's own fields directly. The user picks which models get one with the `models` setting.

## Files in and out

- Pass a library file to any URL field as `"artifact:<id>"` (for example `"image_url": "artifact:abc123"`). It is sent inline, up to 20 MB per file.
- Output files are downloaded into the library. The result lists them in `artifacts` (`id`, `url`, `mime`), and inside `output` each file is replaced by its `artifact_id`. fal links expire, so never hand the user a fal URL.

## Cost notes

- Every run is billed to the user's fal account. Video models cost the most (often per second of output), then image models (per image or megapixel), then audio.
- Check the price in `fal_describe_model` and say it before running expensive models, long videos or `num_images` above 1.
- Searching and describing models is free.

## Setup

Running models needs `FAL_KEY`, created at https://fal.ai/dashboard/keys. If a call fails with `MISSING_SECRET`, ask the user to set it. An HTTP 401 or 403 means the key is wrong or the account has no credit.

## Tips

- Prefer the model's own enums (for example `aspect_ratio`, `duration` as a string like `"5"`) exactly as `fal_describe_model` shows them.
- Edit and image-to-video models usually have `-edit` or `image-to-video` in their id and need an input image field such as `image_urls` or `start_image_url`.
- A job that runs longer than the `max_wait_minutes` setting is cancelled on fal's side too. Any error after a job was submitted quotes its `request_id`; collect it with `fal_get_result` (`{model, request_id}`) instead of running the model again, which would bill twice.

## Needs live verification

These behaviours come from fal's docs and were not checked against the live API:

- Whether fal answers 400 to a result fetch while the job is still in progress (the pack treats that as "not ready").
- Output files on hosts other than `fal.media` (the pack downloads only from known fal hosts).
- The `audio_setting` shape for MiniMax speech models.
